Method
------
Base = blend_proj (fallback own/dff).
Batters: savant_adj = blend * clip(0.08*z_xwoba + 0.03*z_barrel, ±0.18)
Pitchers: savant_adj = blend * clip(0.1*z_xera + 0.0*z_hh_against, ±0.2)
  (z_xera / z_hh inverted so lower xERA / hard-hit = positive)
savant_proj = max(0.1, blend_proj + savant_adj)
value = savant_proj / (salary/1000)
